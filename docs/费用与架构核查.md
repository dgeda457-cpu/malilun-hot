# 费用与架构核查

核查日期：2026-10-20。仅记录本次实际操作和官方说明，不承诺免费平台永远不变。

## 实际采用

1. Sites：使用当前Work环境已有的托管能力，提供免费子域名形式的访问地址。没有新开服务器、购买域名、绑定支付方式或启用用户云账号的按量计费产品。Sites的长期额度与保留政策依当前账户权益；工具未提供一份可独立核实的完整计费/配额表，因此不把Sites写成“永久免费、无限量”。
2. GitHub公开仓库：源码、公开JSON、RSS与采集日志存于 `dgeda457-cpu/malilun-hot`。
3. GitHub Actions：只使用标准 `ubuntu-latest` 运行器，官方说明公开仓库的标准托管运行器免费。工作流还检查仓库必须公开；改为私有时自动跳过采集，避免未经核查进入私有仓库的用量结算。
4. Python与BeautifulSoup：免费开源；前端原生HTML/CSS/JS，无第三方付费SDK、字体、图片或分析服务。

没有 AI API 调用，也不设置 AI API 密钥。网站没有数据库、动态后台、邮件、主动推送或付费代理依赖。

## 官方额度与条件

- [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions)：公开仓库标准运行器免费；较大型运行器即使公开仓库也收费，本项目未使用。免费账户列示500MB artifact storage、2000分钟私有仓库时长与10GB cache，本项目不上传Actions artifacts、不使用Actions缓存，也不依赖私有仓库额度。
- [GitHub scheduled workflows](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)：定时任务可能延迟或丢弃；工作流须在默认分支；公开仓库60天无活动可能停用。项目每日实际保存核验结果会形成提交，仍需偶尔查看。
- [GitHub Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)：候选备用托管，发布站点上限1GB、每月100GB软带宽限制。当前未启用Pages，不将其说成已部署。
- [Cloudflare Pages limits](https://developers.cloudflare.com/pages/platform/limits/)：候选备用托管，Free每月500次构建、20000个文件、单文件25MiB。当前没有新建用户Cloudflare账户或项目。

## 维护与潜在风险

- GitHub原始文件在部分网络可能不可达或受限；网站保留随站备份并显示备份日期。不能把可回退理解为备份每天自动重新发布。
- 数据和原始通知可能变化；有限栏目采集不能代表全领域、全部院校或全部论文。
- 后续若变更托管、改为私有仓库、开较大型运行器、启用付费API或其他计费服务，须重新核查费用，不能沿用本报告。
- 目前在同一天验证了两次云端执行，不是连续7天稳定性结论。
