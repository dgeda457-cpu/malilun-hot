## 4. 日期、热点和学术解释的边界

10项论文具有来源明确的精确出版日；其余论文保留年期和网页日期，不推算某期具体出版日。首次发现时间、最近HTTP核验时间另行保存。

关注榜按“独立成果数 → 独立期刊/出版机构数 → 最近出版日”排序。只统计核实精确出版日的去重论文/著作；会议、重复采集和转载次数不加分。当前7天、30天缺少合格样本，明确显示不足；90天统计主要来自一个期刊，标注样本有限。这是监测范围统计，不能当作全学科热度或学术价值判断。

预设主题按题名、作者提供的关键词和短摘要字面匹配；没有自动推断理论继承、政策因果、研究转向或创新空白。研究问题只展示原始题名中明确包含的问题表达。无摘要则不生成摘要，无全文则不生成“主要观点/方法/结论”。

日报按首次发现时间和UTC日期编排，初期包括历史资料，明确不是“当天发表的全部成果”。全部来源失败时保留旧数据及旧成功日期，不生成假新闻或新一期日报。网站时间显示采用纽约时区，原始文献日期保持来源原样。
