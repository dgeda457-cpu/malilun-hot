# 马理论 HOT 使用与维护说明

## 怎样打开

访问 <https://malilun-hot.fast-plum-3707.chatgpt.site>。无需登录，无投稿、评论或管理入口。可将网址加入浏览器书签。

首页主要展示学术成果与关注榜。点题名打开详情，再点“打开原始来源”核对。只有基本信息的资料不会生成主要观点。日期未知表示证据不足，不表示最近发表。

## 自动更新是否需要电脑开机

不需要。采集在 GitHub 免费云端标准运行器执行，每天两次。计划为11:23和23:23 UTC；纽约夏令时为07:23和19:23，冬令时为06:23和18:23。任务排队可能延迟或偶尔丢弃，不能保证准点。

网站先读取随站备份，然后尝试读取仓库最新数据。若 GitHub 原始文件在当地网络不可达，会显示备份及其真实日期，不显示虚假“刚更新”。前端重新发布前，备份不会自动变新；云端数据正常时始终使用最新仓库数据。

## 怎样查看更新成功

1. 网站打开“信源与方法”，查看最近成功核验时间、云端执行记录和各来源结果。
2. 打开 <https://github.com/dgeda457-cpu/malilun-hot/actions>。
3. “每日学术采集与校验”旁绿色勾表示流程成功；再看网站本次取得多少条记录。流程成功不等于四个来源都成功。
4. “首次发现”和“发表日期”是两个概念。首次上线时收录较早文献属于正常初始化。

## 某个信源失败怎么办

无需马上操作，其他来源继续运行，旧资料保留。网站会显示失败URL、原因、最近成功时间。403/401/429表示受限，本轮会停止该来源详情请求，不尝试绕过。下一次日常计划会重新检查公开可访问性。

连续失败时，先打开原站确认能否正常访问；不要购买代理或验证码服务。需要换栏目或修复解析时，把失败日志交给开发助手。若出现错误内容，用原始官方网页作为纠错证据。

## 怎样增加期刊或高校网站

不是只填网址就能保证采集成功。请先提供该站真实列表页和一篇详情页，让开发助手检查robots、使用说明、真实HTTP响应和字段，再修改 `config/sources.json`。现有解析器适配本项目四个站的页面结构；同类站点仍需验证。

没有可靠证据时不要把新来源直接设为“已核实”。每站每轮默认最多15—22篇，至少1.2秒间隔；新增来源时保持低频。期刊出版权限与可访问性分别核查。

## 怎样修改研究主题

在仓库找到 `config/topics.json`，点铅笔编辑。例如一个主题由 `id`、`name`、`keywords` 组成。保留英文id，只改名称或关键词最稳妥。关键词采用精确字面匹配，不会理解同义词，必要时加入几种表述。

修改后点“Commit changes”保存。配置变动会触发更新。想由助手操作时，直接说明要增加或删除哪些关键词，无需自己编辑。

## 怎样人工纠错

在 `config/corrections.json` 的 `exclude_urls` 加入需撤除的原始URL；或在 `overrides` 中按原始URL填写修正字段，同时提供 `correction_evidence` 官方证据URL。不可凭估计补全日期与作者。保存后等下一次任务，或手动执行任务。

## 怎样手动执行

在 Actions 页面选择“每日学术采集与校验”，点击“Run workflow”，再确认运行。不会调用AI API，也不需要输入密钥。不要在网站前端粘贴密码、Token或投稿账号。

## 我的雷达与RSS

在“我的雷达”输入关键词并保存。配置仅在本浏览器；电脑和手机分别设置。换设备时导出JSON配置，再在新设备导入。清空浏览器数据前先导出。

RSS提供全站、三个栏目和九个预设专题。专题页右上角有专题RSS，网站底部有全站RSS。订阅地址来自公开仓库的原始XML文件；有些网络可能无法访问GitHub。

## 怎样备份

在仓库主页点“Code → Download ZIP”下载完整项目；公开数据在 `public/data/`，RSS在 `public/feeds/`，采集证据在 `evidence/run-*.json`。Git历史还可追溯过去版本。雷达配置要在本地单独导出，不会上传仓库。

## 免费服务停止后怎样恢复

若Actions显示定时任务停用，打开工作流点“Enable workflow”，再手动运行。GitHub公开仓库60天没有仓库活动时可能自动停用定时任务；本项目正常保存数据会有提交，但仍应偶尔查看运行记录。

若Sites不可用，完整源码可转为GitHub Pages：仓库 Settings → Pages → Source 选择GitHub Actions，再让开发助手添加Pages发布配置。也可将 `dist` 导入Cloudflare Pages免费静态托管。两者都无需买域名。不要开启付费套餐或填写支付方式；先核查当时官方免费条件。

若网络无法访问 GitHub，网站仍能显示最近一次随站备份；可让助手重新发布最新静态备份。任何免费平台均不能承诺永久可用。
